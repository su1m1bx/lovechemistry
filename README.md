# 러브 앤 케미스트리 · 첫 시제품

Node.js 20.19+ 또는 22.12+ 환경에서 실행합니다.

```sh
npm install
npm run dev
```

브라우저에서 터미널에 표시된 로컬 주소를 엽니다.

- `npm run build`: 정적 파일 `dist/` 생성. 상대 경로를 사용하여 GitHub Pages의 저장소 하위 경로에서도 동작합니다.
- `npm run preview`: 빌드 결과 로컬 확인.
- `npx playwright install chromium` 후 `npm test`: 실제 브라우저 경로 검증.

## 플레이

새 게임에서 이름을 입력하고 대사창의 **다음**과 선택지를 누릅니다. 점심은 한 장소에서 한 행동, 방과후는 자유 행동 또는 한 명과 동행 한 번입니다. 공부는 받은 핵심 노트 재열람, 스킵은 휴식이며 점수 보너스가 없습니다.

실험은 순서를 선택한 뒤 **시료 선택 → (식염수는 식염 넣기 → 완전히 녹이기) → 측정**으로 조작합니다. 같은 동행 안에서 계속 진행하며 실제 측정한 결과만 관찰 기록에 남습니다.

**저장**은 브라우저 LocalStorage의 단일 슬롯에 현재 장면, 대사 위치, 호감도, 선택 및 점수 적용 기록, 경험 기록, 노트와 실험 상태를 함께 기록합니다. **불러오기**는 슬롯 전체를 복원합니다. 자동 저장은 아니며, 새 게임만으로 기존 저장은 지워지지 않습니다. 브라우저 데이터 삭제 시 저장도 삭제됩니다.

## 구현 범위

`docs/story.md`의 A-01~05, B-01~05 나트륨 대표 경로, C-01~07 전체 선택 분기. 캐릭터 영역은 이름만 표시하며 이미지는 없습니다. 2일차 나머지 네 장소는 선택 전에 미구현 표시로 비활성화되어 있습니다. 3일차 이후·시험·엔딩은 포함하지 않습니다.

임시 수치와 관계 단계는 `src/config.js`, 사건 및 실험 상태 전환은 `src/engine.js`에 있습니다. `src/script.js`가 원문 장면 ID와 표에서 대사·선택지를 읽습니다. 대본 표 구조를 바꾸면 대응하는 선택 지점과 테스트도 확인해 주세요.

## GitHub README와 Pages

제공된 프로젝트 폴더에는 Git 원격이 없어 실제 프로젝트 URL은 아직 설정되지 않았습니다. 실제 README 주소로 `VITE_README_URL=https://github.com/소유자/저장소#readme` 환경 변수를 설정하여 실행·빌드하면 도움말이 연결됩니다. 미설정 시 연결 대상을 안내합니다.

빌드된 `dist/`를 GitHub Pages 정적 소스로 사용할 수 있습니다. 자동 공개 배포 워크플로는 추가하지 않았습니다.
