# 러브 앤 케미스트리 · 첫 시제품

Node.js 20.19+ 또는 22.12+ 환경에서 실행합니다.

```sh
npm install
npm run dev
```

브라우저에서 터미널에 표시된 로컬 주소를 엽니다.

- `npm run build`: 정적 파일 `dist/` 생성. 상대 경로를 사용하여 GitHub Pages의 저장소 하위 경로에서도 동작합니다.
- `npm run preview`: 빌드 결과 로컬 확인.
- `npx playwright install chromium` 후 `npm test`: 실제 브라우저 경로 검증.

## 플레이

새 게임에서 이름을 입력하고 대사창의 **다음**과 선택지를 누릅니다. 점심은 한 장소에서 한 행동, 방과후는 자유 행동 또는 한 명과 동행 한 번입니다. 공부는 받은 핵심 노트 재열람, 스킵은 휴식이며 점수 보너스가 없습니다.

실험은 순서를 선택한 뒤 **시료 선택 → (식염수는 식염 넣기 → 완전히 녹이기) → 측정**으로 조작합니다. 같은 동행 안에서 계속 진행하며 실제 측정한 결과만 관찰 기록에 남습니다.

**저장**은 브라우저 LocalStorage의 단일 슬롯에 현재 장면, 대사 위치, 호감도, 선택 및 점수 적용 기록, 경험 기록, 노트와 실험 상태를 함께 기록합니다. **불러오기**는 슬롯 전체를 복원합니다. 일반 일과는 수동 저장이며, 시험 제출·결과 확인, 확장 구간 인계, 헬륨 요청 및 엔딩 진행은 저장 후 이어집니다. 새 게임만으로 기존 저장은 지워지지 않습니다. 브라우저 데이터 삭제 시 저장과 헬륨 요청 원장도 삭제됩니다.

## 구현 범위

새 게임부터 30일차 방학식까지의 일과, 10·20일차 시험, 7인과 솔로 결말을 연결했습니다. 30일 두 행동 뒤 호감도 80 이상인 인물만 후보가 되며, 복수 후보는 직접 선택합니다. 헬륨의 후반 동행은 수락·거절과 연속 거절 완충을 적용하므로 특정 결말을 보장하지 않습니다. 배점이 미정인 `LATE-HE-INTERVAL`은 제공하지 않습니다. 캐릭터·스냅 이미지가 없어도 텍스트 대체로 진행할 수 있습니다.

임시 수치와 관계 단계는 `src/config.js`, 사건 및 실험 상태 전환은 `src/engine.js`에 있습니다. `src/script.js`가 원문 장면 ID와 표에서 대사·선택지를 읽습니다. 대본 표 구조를 바꾸면 대응하는 선택 지점과 테스트도 확인해 주세요.

## GitHub README와 Pages

도움말은 기본적으로 이 저장소의 README로 연결됩니다. `VITE_README_URL` 환경 변수로 주소를 변경할 수 있습니다.

빌드된 `dist/`를 GitHub Pages 정적 소스로 사용할 수 있습니다. 자동 공개 배포 워크플로는 추가하지 않았습니다.

## 공개 파일 범위

이 프로젝트는 미완성 시제품입니다. 내부 기획 문서, 개인 메모, 에이전트 작업 기록과 편집기 상태는 공개 소스에서 제외합니다.

`docs/story.md`와 `docs/science-reference.md`는 게임과 테스트가 직접 사용하는 런타임 입력이므로 공개 저장소에 유지합니다. 빌드 결과에도 해당 데이터가 포함될 수 있으므로 비공개 메모나 인증정보를 넣지 마세요.
