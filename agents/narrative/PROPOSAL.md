## 1. 제안 목적

30일의 고정 학기 구조 안에서 공통 학교생활과 일곱 공략 루트가 함께 진행되는 서사 골격을 제안한다. 화학 지식은 인물의 감정을 결정하는 법칙이 아니라 단서 확인, 비교, 공부, 약속 이행에 쓰이는 판단 도구로 배치한다.

핵심 방향은 다음과 같다.

- 30일을 세 번의 시험을 기준으로 `적응`, `관계 확장`, `개인 문제`, `선택과 결말`의 네 흐름으로 조직한다.
- 공통 루트는 장소·인물·공부·주기율표·미션을 소개하는 학교생활 축으로 유지한다.
- 개별 루트는 공통 축을 대체하는 별도 세계선이 아니라 점심·방과 후 선택으로 진전되는 겹침 구조로 제안한다.
- 모든 캐릭터 엔딩은 호감도 80 이상과 별개로 필수 이벤트·미션 체인을 요구한다.
- 일곱 루트는 같은 화학 문제의 인물명 교체가 아니라 각자의 관계 과제를 중심에 둔다.
- 비공략 원소 13명은 족·주기 비교, 미션 전달, 다인 이벤트의 기능 슬롯만 부여하고 성격·외형·말투를 확정하지 않는다.
- CG는 사건의 감정적 전환점만 후보로 표시하고 구도, 색, 외형, 복장, 표정 설계는 하지 않는다.

상세 내용은 `docs/04_NARRATIVE_PLAN.md`에 승인 구현 결정과 콘텐츠 제안을 구분해 작성한다.

## 4. 가정과 미정 사항

### 작업 가정

- 일반일의 고정 순서는 아침 조회, 오전 수업, 점심 자유 시간, 오후 수업, 방과 후 자유 활동, 귀가·일 종료다.
- 활성 회차가 Day 10, 20, 30에 도달하면 오후 수업 뒤 시험이 반드시 발생하며, 50점 미만이면 그 즉시 퇴학 게임 오버가 우선한다. 합격 시 보류 후보가 있으면 즉시 엔딩 흐름을 재개하고, 없으면 같은 Day 방과 후와 `dayEnd`로 진행한다.
- 공통 필수 장면은 가능한 한 조회·수업·일 종료 같은 고정 구간에 놓아 자유 행동 기회를 몰래 소모하지 않는다. 정확한 배치는 시스템 승인 대상이다.
- 개별 루트 이벤트는 권장 일자 범위를 가지되, 필수 체인의 선후 관계를 지키는 범위에서 일정한 유예 폭을 둔다.
- 미션에 필요한 과학 정보는 사전에 수업에서 배우거나 주기율표에서 조회할 수 있다.
- 연애 성립은 캐릭터 엔딩에서만 확정하고, 그 이전은 친밀감과 긴장감의 변화로 다룬다.

### 승인 구현 결정

- Day 30은 `조회 → 오전 수업 → 점심 → 오후 수업 → 시험 → 합격 시 방과 후 → dayEnd`이며 노멀 엔드 뒤 Day 31은 없다.
- 캐릭터 엔드는 조건을 완성한 효과 트랜잭션 직후 판정한다. 도달 시험 미완료면 합격까지 보류하고 퇴학을 우선하며, 단일 또는 선택한 동시 후보의 실패 없는 최종 장면 뒤 정확히 하나를 terminal로 확정한다. 이후 미래 시험은 진행하지 않는다.
- 각 집중 루트의 제안 단계 정적 예산은 시험 공부를 포함해 42행동 이하이고, 최종 데이터는 최초 완료 Day 29 이내, 그 시점까지 도달한 시험 합격, 실제 가용 행동과 보상 합을 함께 증명해야 한다. 예산에 쓰는 양수 델타는 `+1`, `+3`, `+5`, `+8`뿐이다.

### 미정 사항

- OQ-001은 사용자 결정으로 해소됐고 주인공은 남성 고정, 이름은 사용자 입력이다. 남성이라는 사실은 반영할 수 있으나 외형·신체·복장 또는 성별 고정 연애 역할을 발명하지 않는다.
- 필수 이벤트 실패 후 재시도 콘텐츠와 개별 보상 배치는 미정이다. 최종 데이터는 승인된 정적 예산을 바꾸지 않고 충족해야 한다.
- 최종 미션 아이템명, 상세 대사, 정확한 CG 제작 목록은 미정이다.

## 5. 잠금 규칙 영향

### 준수하는 잠금

- 30일 학기 상한과 활성 회차가 도달한 Day 10·20·30 시험을 유지하며, Character End 뒤 미래 시험 미실행은 승인 예외로 적용한다.
- 시험 50점 미만 즉시 퇴학, 호감도 시작값 10과 전역 임계값, 호감도 80만으로 엔딩을 우회할 수 없다는 규칙을 변경하지 않는다.
- 캐릭터 엔딩, 노멀 엔드, 퇴학 게임 오버를 모두 보존한다.
- H, C, O, F, Na, Cl, Ne의 학년·역할·성격·말투·관계 시드·과학 모티프를 변경하지 않는다.
- 과학 범위를 원자번호 1~20과 승인된 고등학교 1학년 수준으로 제한한다.
- 화학적 관계를 연애의 필연으로 표현하지 않는다.
- 학교를 기능적으로 평범하게 유지하고 추가 세계관을 만들지 않는다.
- 매점은 버튼으로만 사용하며 지도 장소로 추가하지 않는다.
- CG 갤러리의 홈 전용 규칙과 무음 규칙을 침범하지 않는다.
- 캐릭터 비주얼과 상세 대본을 확정하지 않는다.

### 승인된 잠금 영향

결정 020의 조기 성공 종료와 미래 시험 미실행은 사용자 승인 예외이며 결정 021은 시험 중 비허용 결정을 제한 기본 조회로 대체한다. 본 제안이 추가 잠금 변경을 요청하지는 않는다.

## 6. 주요 절충과 대안

### 절충 A: 30일 밀도와 일곱 루트 도달성

- **안 1, 권고:** 공통 축은 고정 시간대에, 개별 루트는 자유 시간에 겹쳐 진행한다. 한 회차에서 여러 루트를 탐색할 수 있지만 완주는 선택과 자원 배분을 요구한다.
- **안 2:** 초반 공통 루트 뒤 한 캐릭터에 조기 고정한다. 검증은 쉽지만 C의 다인 관계와 학교생활의 개방감이 약해진다.
- **안 3:** 모든 루트 이벤트를 넓게 허용한다. 콘텐츠 발견은 쉬우나 30일 자원 압박과 재플레이 가치가 약해진다.

### 절충 B: 필수 이벤트의 일자 고정도

- **안 1, 권고:** 시험과 공통 거시 비트만 정확한 Day에 고정하고 개별 이벤트는 일자 범위와 선행 조건으로 연다.
- **안 2:** 모든 필수 이벤트를 특정 Day에 고정한다. 연출은 선명하지만 한 번의 선택으로 루트가 예고 없이 영구 차단될 위험이 크다.
- **안 3:** 일자 제한을 없앤다. 소프트락은 줄지만 30일의 시간성이 희미해진다.

### 절충 C: 조연 13명의 활용량

- **안 1, 권고:** 각 조연에게 교육·전달·비교 중 하나의 최소 기능만 부여하고 여러 루트가 공유한다.
- **안 2:** 조연마다 독립 서브스토리를 둔다. 세계는 풍부해지지만 범위와 주요 루트 의존성이 급증한다.
- **안 3:** 이름만 등장시킨다. 제작량은 줄지만 C·Na 루트와 족·주기 비교가 빈약해진다.

### 절충 D: Ne의 고난도와 공정성

- **안 1, 권고:** 반복 선물 대신 관찰 가능한 등장 규칙, 18족 비교 학습, 거리 존중 선택, Ne가 먼저 제안하는 사건을 필수 체인으로 둔다.
- **안 2:** 조건을 완전히 숨긴다. 히든 감각은 강하지만 공략 정보 없이는 불공정할 수 있다.
- **안 3:** 일반 루트처럼 표시한다. 도달성은 높지만 숨겨진 고난도 정체성이 약해진다.

Character End가 먼저 발생하지 않은 공통 루트는 `전학생의 자리 → 학교 사용법 → 첫 요청 묶음 → 시험 준비망 → 시험 후 태도 → 교내 공동 정리 → 겹치는 약속 → 학기 마무리 → Day 30 Normal End 판정`으로 이어진다. 시험 외 개별 이벤트는 특정 하루가 아니라 권장 구간과 선행 조건으로 열어 예고 없는 영구 차단을 줄인다.

### 일곱 루트

| 루트 | 이벤트·필수 체인 요약 | 핵심 미션 | 엔딩 비트 |
|---|---|---|---|
| H | 첫 동행 → 분실물 → H·Na·K의 공통점과 차이 → 고립에 관한 진지한 말 → 상호 초대 | 장소 단서로 개인 물건 찾기, 1족 비교에서 H의 차이 확인 | 늘 먼저 다가오던 H와 주인공이 서로의 의사를 확인하고 연인 관계 선택 |
| C | 자연스러운 환영 → 다인 요청 → C의 욕구가 비는 순간 → 대신 정하지 않기 → 개인적 부탁 | 조연 요청 연결, 여러 기대 밖에서 C의 실제 선택 확인 | C가 모두의 답이 아닌 자신의 관계를 직접 선택 |
| O | 첫 도움 → 공동 공부 계획 → 오류 자료 대조 → 계획이 흔들리는 순간 → 서로 설명하기 | 선행 학습이 있는 공동 노트, 빠진 자료 찾기와 정본 대조 | 도움을 주고받으며 함께 이해하는 연인 관계 선택 |
| F | 즉답 요구 → 기한 있는 부탁 → F·Cl 비교 → 바뀐 상황의 재합의 → 무게 있는 답 | 17족 단서의 정확한 전달, F·Cl 공통점과 차이 확인 | 빠르지만 빈말이 아닌 상호 답변으로 관계 성립 |
| Na | 즉흥적 합류 → 매점 부탁 → 커진 계획 → 공동 수습 → 둘의 다음 계획 | 버튼형 매점 주문 정리, H·Na·K 비교로 담당 연결 | 재미와 책임을 함께할 다음 약속을 합의 |
| Cl | 필요한 안내 → 첫 전달 약속 → F와 다른 결단 → 숨은 부담 → 신뢰를 맡김 | 연속 전달, 족·주기 단서로 정리 업무 분담 | 누적된 약속 이행을 근거로 책임을 나누는 관계 선택 |
| Ne | 반복 가능한 존재 단서 → 강요 없는 대화 → 18족 비교 → 방해하지 않는 약속 → Ne의 제안 | He·Ne·Ar 비교, 학습·거리 존중·과잉 선물 회피의 복합 조건 | 필요가 아니라 자발적 선택으로 특별한 관계 성립 |

각 행의 체인은 호감도와 별개인 필수 조건이다. `docs/04`·`docs/05`의 제안 단계 예산은 구현 전 정적 검증 계약이며, 개별 보상 배치와 상세 콘텐츠는 확정하지 않는다.

Na의 잠긴 `반복적 참여 거부`는 일반적인 타 캐릭터 공략 선택을 뜻하지 않는다. 일반 초대 거절, 일정 충돌, 정중한 불참은 기본 호감도 `0`이며, 관계 맥락에서 지속적으로 Na를 배제하거나 명시적 약속을 깨고 책임을 회피하거나 이미 수락한 공동 계획에서 무책임하게 이탈하는 서사 선택에만 `-3/-6` 등 승인 델타를 연결한다. 이 해석은 Character Bible의 잠금 성향을 변경하지 않는다.

### 비공략 원소와 CG

- He·Ar은 18족 비교와 Ne 루트 발견 보조, Li·K는 H·Na와 1족 비교, Be·Mg·Ca는 2족·주기 비교에 쓴다.
- B·Si는 C 주변의 14족·주기 비교, N·S는 O 주변의 같은 주기 또는 같은 족 비교, Al·P는 3주기 자료 정리와 전달에 쓴다.
- 이 13명에게는 요청자·수령자·비교 대상이라는 최소 기능만 주며 학년, 성격, 말투, 외형, 독립 서브스토리를 확정하지 않는다.
- CG 후보는 공통 전학 첫날, 각 루트의 개인 전환점, 일곱 캐릭터 엔딩으로 구성한 후보 풀이다.
- CG 후보에는 사건 기능과 스포일러 등급만 붙이고 외형, 구도, 색, 복장, 표정, 화풍, 화면 비율을 정하지 않는다.

상세한 사건 목적, 미션 경계, 조연별 기능 및 CG 임시 후보 ID는 `docs/04_NARRATIVE_PLAN.md`에 제안 상태로 기록한다.
