# QA 계획

**상태:** `V2 PRE-IMPLEMENTATION REVIEW PASS / S0~S2 READY FOR PM IMPLEMENTATION AUTHORIZATION / IMPLEMENTATION NOT APPROVED·NOT TESTED`  
**작성일:** 2026-09-28  
**범위:** 잠금 규칙, 다섯 역할의 2차 설계, 구현 전 계약 검토 및 구현 후 인수·회귀 기준

## 1. 목적과 현재 판정

이 문서는 《러브 앤 케미스트리》의 구현 전·후 품질 게이트를 정의한다. QA는 잠금 규칙을 변경하거나 제품을 재설계하지 않으며, 제안 간 계약을 임의로 선택하지 않는다.

2026-09-03 재검토의 결정 004~021 계약 `PASS`는 과거 이력으로 유지한다. 2026-09-28에는 다섯 `DESIGN_V2.md`, `docs/00`~`12`, 결정 022~046을 재검토했다. 결정 043~046으로 High 2건과 Medium 2건의 문서상 원인이 해소되어 QA-V2-001~004는 `CLOSED`다. Slice 0~2는 `READY FOR PM IMPLEMENTATION AUTHORIZATION`이지만 아직 구현 승인은 없고 코드·최종 콘텐츠·자산·production build·배포는 `NOT TESTED`다.

- 시험일은 세 Day 모두 `morningHomeroom → morningClass → lunchFreeTime → afternoonClass → exam → 합격 시 afterSchoolFreeTime → dayEnd`로 정렬됐다. 과거 `QA-002`는 `CLOSED`이고 OQ-002도 결정 020으로 `RESOLVED`다. 효과 완료 직후 Character End를 판정하되 현재 또는 도달 시험 미완료 시 합격까지 보류하고 퇴학을 우선한다.
- 일곱 집중 루트는 시험 공부를 포함해 28~41행동이고 총 60행동 중 19~32행동을 남긴다. Ne는 일반 상호작용 최대 `+12`로 시작값 포함 22에 그치며, 필수 체인 `+29`와 특수 행동 `+32`를 포함하면 83이다.
- 호감도는 게임플레이 cap·clamp 없는 JavaScript 안전 정수, 미션은 일곱 상태로 통일됐다.
- 저장은 Day 시작을 기본으로 하고 세 시험 합격 직후 `examResolved/afterSchoolFreeTime`, 실패 및 결말은 terminal로 원자 커밋한다.
- 주인공은 선택·nullable 상태 없이 `gender = male`로 확정됐고 외형은 계속 유예다.
- 무료 수업은 주제별 `0→1`만 가능하며 숙련도 `2·3`은 자유 행동 슬롯을 쓰는 혼자·함께 공부로만 얻는다. 단계별 실질 효용과 핵심 사실 기본 조회를 유지하고 시험 점수·정답 자동 보정은 금지하며, 무료 수업은 시험 공부 행동 예산을 대체하지 않는다.
- 시험별 고정 10문항×10점과 `49/50/100` 경계는 승인 유지다. 시험 중에는 원소 1~20의 승인된 기본 사실과 공간 배열·상세만 조회할 수 있고 검색·필터·비교·힌트·오답 진단은 금지된다. 답안·문항 순서·현재 위치·복귀 포커스를 보존하며 자동 정답·점수 보정은 없다.
- Na의 일반 초대 거절·일정 충돌·미리 알린 정중한 불참은 `0`이고, 명시적 약속 파기·책임 전가·수락한 공동 계획에서의 무책임한 이탈 같은 관계적 위반에만 승인 음수 델타를 적용한다.

이 판정은 문서 계약만 대상으로 한다. 코드, 최종 콘텐츠 데이터, 자산, production build와 배포가 없으므로 기능·통합·접근성·배포·출시는 `NOT TESTED`이며 Slice 0~3 또는 전체 구현 승인으로 해석하지 않는다.

상세 finding의 최신 상태와 다음 게이트는 `agents/qa/REPORT.md`, 실행 가능한 상세 테스트는 `agents/qa/TEST_PLAN.md`를 따른다.

## 6. 마스터 최소 수용 행렬

아래는 `docs/00_PM_MASTER_SPEC.md` 32절의 모든 항목을 누락 없이 포함한 출시 최소 행렬이다.

### 과학

- [ ] 원소 1~20의 원자번호와 기호가 모두 정확하다.
- [ ] 족·주기 데이터가 정확하고 일관된다.
- [ ] 전자배치가 승인된 전자껍질별 단순화와 일치한다.
- [ ] 시험이 범위 밖 고급 화학을 요구하지 않는다.
- [ ] 서사가 정본 과학 데이터와 모순되지 않는다.

### 호감도 경계

- [ ] 음수 값에서 관계 악화 상태가 적용된다.
- [ ] 정확히 20에서 친한 친구 상태가 적용된다.
- [ ] 정확히 40에서 썸 상태가 적용된다.
- [ ] 80만으로 필수 미션·이벤트를 우회하지 못한다.
- [ ] 80과 필수 루트 조건을 모두 충족하면 루트 성공이 가능하다.

### 시험

- [ ] Day 10 시험이 발생한다.
- [ ] Day 20 시험이 발생한다.
- [ ] Day 30 시험이 발생한다.
- [ ] 49점은 퇴학이다.
- [ ] 50점은 생존이다.
- [ ] 저장·불러오기로 필수 시험을 건너뛸 수 없다.

### 결말

- [ ] 최소 한 개 이상의 캐릭터 엔드가 도달 가능하다.
- [ ] 노멀 엔드가 도달 가능하다.
- [ ] 퇴학 게임 오버가 도달 가능하다.
- [ ] 어떤 결말도 불가능한 사후 상태를 만들지 않는다.

### 저장

- [ ] 저장·불러오기가 Day와 필수 상태를 복원한다.
- [ ] 루트·이벤트 플래그가 재로드 뒤 유지된다.
- [ ] 인벤토리가 재로드 뒤 유지된다.
- [ ] 호감도가 재로드 뒤 유지된다.
- [ ] 손상·구버전 저장에 정의된 대체 처리가 있다.

### Ne 루트

- [ ] 일반 호감도 반복으로 히든 루트를 쉽게 우회할 수 없다.
- [ ] 특수 조건을 발견하고 충족할 수 있다.
- [ ] 어렵지만 불가능하지 않다.

### 갤러리

- [ ] 홈에서 갤러리에 접근할 수 있다.
- [ ] 활성 게임에서 갤러리에 접근할 수 없다.
- [ ] CG 해금이 설계대로 영속된다.

### 무음

- [ ] 깨진 오디오 UI나 유령 음량 설정이 없다.

### 배포

- [ ] production build가 GitHub Pages에서 실행된다.
- [ ] 모든 자산 경로가 정상 해결된다.

- 통합 검증: Systems-State-UI 사이의 명령과 복원 결과, 효과 멱등성, 실패 원자성을 검사한다.
- E2E 검증: Day 1~30 대표 경로, 일곱 집중 루트, 노멀 엔드, 세 시험 퇴학, 갤러리 및 Pages를 검사한다.
- 수동 검증: 과학 문맥, 캐릭터 불변성, Ne 단서 공정성, 화면 낭독기, 모바일 실제 기기, 스포일러를 검사한다.

각 실행은 빌드·콘텐츠·스키마 버전, 브라우저, 뷰포트, 시드, 시작 fixture, 단계, 기대·실제 결과, 스크린샷 또는 상태 덤프를 남긴다. 필수 경로에는 난수를 사용하지 않는다.

## 9. 환경 기준

구현 전 PM이 최소 브라우저 버전을 확정해야 한다. 확정 전 계획 기준은 최신 안정판 Chromium, Firefox, WebKit 계열과 데스크톱·모바일 뷰포트다.

- 데스크톱: 1280×720 이상 대표 폭
- 모바일 세로: 320×568 및 390×844급
- 모바일 가로: 낮은 높이 대표 환경
- 확대: 200%
- 입력: 키보드 전용, 터치, 포인터
- 접근성: 화면 낭독기 기본 흐름, `prefers-reduced-motion`, 색상 비의존 확인
- 배포: 실제 저장소명 하위 경로와 동등한 정적 서버, 루트가 아닌 URL에서 자산 검사
- 저장: 정상, 비어 있음, 접근 거부, 용량 초과, 손상 A/B 버퍼, 구·미래 버전, 다중 탭
