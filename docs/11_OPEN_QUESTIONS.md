# 미해결 질문

이 문서는 답변이 필요한 실제 모순과 의도적으로 나중에 다룰 항목을 구분한다. 유예 항목은 현재 확정 질문이 아니며, 담당 역할의 제안 절차가 시작되기 전까지 임의로 답을 만들지 않는다.

## 확정 필요 질문

2026-10-26 사용자 답변과 결정 054~059를 반영했다. OQ-005는 철회 종료, OQ-007은 기록장 방향으로 해결됐으며 OQ-004·006·008·009는 일부 세부만 남는다. 상세 체크리스트는 [`16_USER_SCENARIO_REVIEW.md`](16_USER_SCENARIO_REVIEW.md), 실험 출처 조사는 [`17_CHEMISTRY_EXPERIMENT_RESEARCH.md`](17_CHEMISTRY_EXPERIMENT_RESEARCH.md)를 따른다. 확정 답변을 다시 묻거나 미정 숫자·대상 쌍·보상을 임의로 만들지 않는다.

### OQ-004 첫날 튜토리얼의 행동 비용과 등장 범위

- **상태:** `PARTIALLY RESOLVED / 대화 상한 확정, 슬롯·등장 범위 미정`
- [x] 첫날 각 캐릭터의 대화는 첫인사 1회·일반 대화 1회, 최대 2회다. 무제한 보상은 아니다(결정 054).
- [ ] 고정 일과의 소개 대화와 점심·방과 후 각 1슬롯을 쓰는 실제 교류를 어떻게 구분할지 확정한다.
- [ ] 첫날 만날 수 있는 인물 범위와 Ne 공략 정보의 공개 수준을 정한다. 원소 Ne의 기본 과학 사실은 처음부터 공개다.
- **기존 기준:** 결정 005, `docs/04` 2·3·11절, `docs/05` 5.2절. 첫날 모든 인물과 무제한 보상 교류한다는 예외는 아직 없다.
- **연결:** SCN-01·02. Day 1 소개·탐색 자체는 충돌하지 않는다.

### OQ-006 타 인물 호감도에 따른 반응 차이의 범위

- [ ] 다른 인물과의 관계가 영향을 주는 구체 맥락·관찰한 사건·약속 상태와 반응을 정한다.

- **연결:** SCN-05. 모든 인물에게 질투 설정을 새로 부여하지 않는다.

### OQ-008 실험 데이트의 인원·15 조건·행동/보상 계약

- **상태:** `PARTIALLY RESOLVED / 보상 방향 확정, 인원·행동 세부 필요`
- **사용자 구상:** 과학실 실험 데이트의 호감도 조건은 **15 이상**, 선택 인원은 **최대 2명**이다.
- [x] 효과는 호감도 상승과 **실제 플레이어의 이해·지식 확장**이다. 아바타 지식 XP·무료 mastery·시험 가산을 자동 보상으로 가정하지 않는다(결정 058).
- [ ] 두 명이 동행 캐릭터 수인지 플레이어 포함 총원인지, 15 조건이 각 참가자에게 적용되는지 확정한다.
- [ ] Ne 등 인물별 발견·초대 수락 조건을 함께 요구할지 정한다. 15만으로 특수 필수 체인을 우회하지 않게 한다.
- [ ] 시간대·슬롯 비용·함께 공부/미션 분류·기존 숙련도와의 연결 여부·캐릭터별 델타·반복 보상 정책을 정하고 루트 예산을 재검증한다. 교육 보상을 수치 상승으로 대체하지 않는다.
- **기존 기준:** 친구 20·썸 40은 관계 단계이므로 활동 해금 15와 직접 충돌하지 않는다. 기존에 실험 15·2인 규칙이 승인돼 있었다고 볼 근거도 없다.
- **연결:** SCN-08·09·11·12. 숫자를 임의로 20·40으로 바꾸지 않는다.

### OQ-009 과학실 실험의 교육 범위와 상호작용 방식

- **상태:** `RESEARCH COMPLETED / 최종 교육·기능 범위 검토 필요`

### OQ-003 시험 중 주기율표 허용 여부

- **상태:** `RESOLVED` (2026-09-03, 결정 021)
- **사용자 결정:** 시험 중 행동 비용 없는 기본 주기율표 조회를 허용한다.
- **계약:** 원소 1~20의 정본 원자번호, 기호, 한국어·영어 이름, 족, 주기, 전자껍질별 전자배치, 승인된 원자가전자 정보와 기본 공간 배열·원소 상세만 제공한다. 검색, 숙련도 기반 족·주기 필터, 두 원소 비교, 복합 비교, 미션·대화 힌트, 오답 진단은 시험 문맥에서 비활성화한다. 답안·문항 순서·현재 위치를 보존한 오버레이로 열고 닫으며 자동 답 선택·점수 보정은 없다.
- **영향 범위:** 시험 UI, 도구 문맥, 포커스·복귀, 런타임 시험 상태, QA

### OQ-002 캐릭터 엔드 판정 시점

- **상태:** `RESOLVED` (2026-09-03, 결정 020)
- **사용자 결정:** 호감도 80 이상, 필수 미션 완료, 필수 이벤트 완료, route-ending condition 도달을 완성한 효과 트랜잭션 직후 Character End 자격을 판정한다.
- **계약:** 후보 1명은 실패 없는 최종 장면 뒤 즉시 terminal Character End를 원자 커밋한다. 하나의 다인 이벤트로 2명 이상이 동시에 자격을 얻으면 그 자격 후보만 표시해 한 명을 고르고 정확히 하나의 엔딩만 확정한다. 현재 시험 또는 이미 도달한 필수 시험이 미완료면 판정을 보류하며 50점 미만 퇴학이 우선한다. 성공 회차는 Day 30 전에 끝날 수 있고 미래 시험은 실행하지 않는다. 성공 없이 진행하면 Day 30 종합 시험 합격 후 방과 후와 `dayEnd`까지 마치고 노멀 엔드가 되며 Day 31은 없다.
- **영향 범위:** 서사 진행, 엔딩 판정, phase, terminal 저장, 메타 해금, 엔딩 UX, 도달성 정적 검증

### OQ-001 주인공 성별 규칙

- **상태:** `RESOLVED` (2026-09-03)
- **기존 모순:** “플레이어 성별은 사용자 입력·선택 가능”과 “주인공은 혼자 사는 남학생”이 함께 존재했다.
- **사용자 결정:** 주인공은 **남성으로 고정**한다. 이름은 계속 사용자 입력으로 유지한다.
- **계약:** 상태의 `gender`는 선택형·대기형이 아니라 고정값 `male`이다. 성별 선택 UI를 만들지 않는다. 남성 확정은 캐릭터 외형 확정이 아니며 주인공의 머리·눈·체형·키·복장 등 비주얼은 계속 유예하고 발명하지 않는다.
- **영향 범위:** 플레이어 설정, 상태 스키마, 호칭·대사, 서사, 테스트

## 유예 항목

다음 항목은 모순 해결 질문이 아니라 적절한 역할의 제안·검토 단계로 의도적으로 미룬 범위다.

- 정확한 캐릭터 비주얼
- PixAI 프롬프트 설계
- 최종 배경 미술
- 비공략 원소 13명의 정확한 성격
- 30일 전체 상세 대본
- 최종 아이템 목록
- 최종 미션 목록
- 최종 시험 문항 은행
- 정확한 CG 목록
- 현재 게임 시스템 외 별도 미니게임
- 자산의 정확한 픽셀 크기와 종횡비
- 간식의 최종 목록·가격·개별 반응, 서사적 선물 거절을 일일 시도에 포함할지와 전달 슬롯. 하루 캐릭터당 전달 최대 1회는 결정 059로 확정

유예 항목은 아키텍처를 불필요하게 막지 않되, 제안과 승인 전에는 제품 결정으로 취급하지 않는다.
