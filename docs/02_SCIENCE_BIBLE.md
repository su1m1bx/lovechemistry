# 과학 바이블

## 1. 목적과 권한

이 문서는 《러브 앤 케미스트리》의 과학 내용 작성, 데이터 구축, 서사 연결, 시험 출제, QA에 적용하는 기준서다. `docs/00_PM_MASTER_SPEC.md`와 충돌하면 마스터 스펙이 우선한다.

- 과학 사실은 서사보다 우선한다.
- 서사 담당자는 화학을 새로 발명하거나 사실을 고칠 권한이 없다. 충돌을 발견하면 문장으로 덮지 말고 PM과 과학 담당자에게 보고한다.
- 과학 담당자는 잠긴 캐릭터 성격이나 이야기 분위기를 과학 편의를 이유로 바꾸지 않는다.
- 과학 사실과 캐릭터·관계에 대한 서사적 해석을 명시적으로 구분한다.

## 2. 교육 범위

### 수준 상한

필수 학습과 평가는 대한민국 고등학교 1학년에서 이해할 수 있는 기초 화학 수준으로 제한한다.

### 핵심 학습 개념

- 원자번호
- 원소명과 원소 기호
- 족과 주기
- 목표 수준에 맞는 전자배치와 전자껍질별 전자 분포
- 필요한 경우의 기초 원자가전자 추론
- 같은 족 원소가 보이는 유사한 화학적 성질
- 주기와 전자가 들어 있는 전자껍질 수의 관계
- 목표 수준에서의 안정한 전자배치
- 원자번호 1~20 원소 사이의 기초 비교

학습은 단순 암기에 머물지 않고 “자료 확인 → 규칙 발견 → 비교·추론 → 학교 안 행동”으로 이어져야 한다.

- 학교 세계에는 1~20번 원소가 모두 캐릭터로 존재한다. 공략 캐릭터가 아닌 13명도 우선 정확한 과학 데이터와 최소 캐릭터 식별자를 가지며, 상세 성격은 별도 승인 전 확정하지 않는다.

## 4. 단일 소스 정책

### 정본 원칙

원소별 과학 사실은 구현 시 하나의 정형화된 정본 데이터셋에서만 정의한다. 파일 형식과 정확한 경로는 기술 결정 사항이지만, 마스터 스펙의 예시는 `src/data/elements.json`이다.

각 원소 항목은 최소한 다음 정보를 가진다.

| 필드 역할 | 내용 |
|---|---|
| 원자번호 | 1~20의 정수이며 원소 식별의 핵심 사실 |
| 원소 기호 | 대소문자를 포함한 표준 기호 |
| 한국어 이름 | 제품 전체에서 사용할 정본 표기 |
| 영어 이름 | 정본 영어 표기 |
| 족 | 현대식 1~18족 번호 |
| 주기 | 주기 번호 |
| 전자배치 | 이 문서의 교육 수준에 맞는 전자껍질별 표현 |
| 원자가전자 정보 | 교육적으로 승인된 범위에서만 제공 |
| 분류·교육 태그 | 검색·수업·비교에 필요한 경우 사용 |

### 참조 규칙

- 주기율표, 공부, 미션, 대화 조건, 시험, 캐릭터 프로필은 모두 같은 정본을 참조한다.
- 장면, 캐릭터, 문제 데이터는 원소 식별자를 참조할 수 있지만 원자번호·기호·족·주기·전자배치를 별도로 재정의하지 않는다.
- 화면 표시용 문구가 필요해도 사실값을 복제해 수동 관리하지 않는다. 정본 값에서 표시를 만든다.
- 과학적 관계를 이벤트 플래그에 임의 사실처럼 분산 저장하지 않는다.
- 정본 변경은 주기율표만 확인하고 끝내지 않는다. 해당 값을 참조하는 공부, 미션, 대화, 시험, 프로필의 회귀 검사를 함께 수행한다.
- 캐릭터 성격 데이터는 과학 정본과 별도 정본으로 관리한다. “과학 사실”과 “그 사실에서 영감을 얻은 인물 해석”을 같은 필드로 혼합하지 않는다.

## 5. 용어와 표기 원칙

### 기본 용어

- `원자번호`: 양성자 수를 나타내는 원소 고유 번호로 설명한다.
- `원소 기호`: 첫 글자는 대문자, 둘째 글자가 있으면 소문자로 쓴다. 예: `H`, `He`, `Na`, `Cl`.
- `족`: 세로 열이며 1~18족 번호를 사용한다.
- `주기`: 가로 행이며, 기초 범위에서는 전자가 들어 있는 전자껍질 수와 연결해 설명한다.
- `전자배치`: 이 프로젝트의 학습 화면과 문제에서는 원칙적으로 전자껍질별 전자 수 배열을 뜻한다.
- `원자가전자`: 목표 수준에서 가장 바깥 전자껍질의 전자로 다룬다. 예외나 고급 결합 설명이 필요한 방식으로 확장하지 않는다.
- `안정한 전자배치`: 목표 수준에서 채워진 가장 바깥 전자껍질을 이해시키는 표현으로 사용한다. “안정”을 인간의 무감정·무관심과 동일시하지 않는다.

### 전자배치 표현

- 기본 표기는 안쪽 전자껍질부터 쉼표로 나열한 전자 수다. 예: H는 `1`, O는 `2, 6`, Na는 `2, 8, 1`, Ca는 `2, 8, 8, 2`.
- 같은 원소는 주기율표, 공부, 시험, 미션, 대화에서 동일한 표기 순서와 구분 방식을 사용한다.
- 1~20번 원소의 기초 학습에서는 전자껍질 분포를 중심으로 족, 주기, 원자가전자 경향을 연결한다.
- 오비탈 기호를 사용한 상세 표기나 오비탈 상자 그림은 필수 정답 지식으로 요구하지 않는다.
- UI가 “전자배치”와 “전자껍질 분포”를 함께 사용할 경우 두 표현이 이 교육 범위에서 같은 표시 대상을 가리킴을 처음에 알려 용어 혼동을 막는다.
- 문항은 표기법 해독 자체보다 원소 비교와 족·주기·원자가전자 추론을 평가해야 한다.

### 이름과 문장

- 한국어 본문은 위 표의 한국어 이름을 일관되게 사용한다. 영문 이름은 데이터·보조 표시에만 사용한다.
- 원소 기호와 캐릭터 ID를 원소명 자체와 혼동하지 않는다.
- 과학적 사실 문장은 관찰·비교 가능한 수준으로 쓴다. 과장된 절대 표현과 인격적 의도를 사실처럼 쓰지 않는다.

## 6. 허용되는 교육적 단순화

다음은 고등학교 1학년 수준과 1~20번 원소 범위를 지키기 위한 표현 원칙이다. 단순화는 사실을 뒤집거나 예외를 숨긴 채 거짓 일반화를 만드는 허가가 아니다.

- 1~20번 원소는 전자껍질별 전자 수로 전자배치를 제시한다.
- 족과 원자가전자 수의 관계는 목표 범위에서 비교·추론에 필요한 수준으로 다룬다.
- 주기와 점유 전자껍질 수의 관계를 기초 규칙으로 사용한다.
- 같은 족 원소의 성질은 “유사한 경향”으로 설명하고 “완전히 동일하다”고 하지 않는다.
- 안정한 전자배치는 목표 수준의 최외각 전자껍질 설명으로 제한한다.
- H는 1족 위치와 전자 하나라는 학습 소재로 H·Na·K 비교에 사용할 수 있지만 알칼리 금속과 단순 동일시하지 않는다.
- F와 Cl은 같은 17족 및 원자가전자 7개 비교, Ne는 18족의 채워진 최외각 전자껍질 비교에 사용할 수 있다.
- C의 연결성, O의 공부 역할 등 캐릭터 모티프는 이해를 돕는 서사 장치로 사용할 수 있으나 과학 정의나 필연적 인간 성격으로 제시하지 않는다.

새로운 단순화 방식이 필요하면 정본에 반영하기 전에 과학 담당자가 정확성과 범위 적합성을 검토하고 PM 승인 절차를 따른다. 잠금 교육 범위 자체를 바꾸는 단순화는 허용되지 않는다.

## 7. 금지 범위

### 필수 학습·평가 금지

- 오비탈 혼성화
- 분자 오비탈 이론
- 고급 양자역학
- 고급 열역학
- 대학 수준 결합 이론
- 상세 반응 속도론
- 고급 전기화학
- 전문 수치 상수 암기
- 원자번호 20을 넘는 원소 지식
- 승인 범위를 넘어서는 기타 고급 화학

### 표현·설계 금지

- 서사적 필요에 맞춰 원자번호, 기호, 족, 주기, 전자배치 등 사실을 변경하는 행위
- 서로 다른 콘텐츠 파일에 과학값을 복제해 상충하는 정본을 만드는 행위
- “Na와 Cl의 화학적 관계가 의미 있으므로 둘은 반드시 연애한다”처럼 화학 상호작용을 인간관계 법칙으로 등치하는 표현
- “반응성이 크면 폭력적이다”, “안정하면 감정이 없다”처럼 성질과 성격을 보편적으로 일대일 대응시키는 표현
- 모든 대화를 화학 퀴즈로 만들거나 모든 캐릭터를 교과서처럼 말하게 하는 구성
- 어려워 보이기 위해 고급 용어를 삽입하는 행위
- 범위 밖 지식이나 전문 상수를 알아야 미션·루트·시험을 통과할 수 있게 하는 행위
- 필수 과학 이벤트를 경로를 깨뜨리는 무작위 조건에 맡기는 행위

## 8. 게임플레이 연결 원칙

과학은 다음 영역에 실제로 작용해야 한다.

- 대화 선택: 배운 개념으로 말의 의미나 더 나은 대응을 이해한다.
- 캐릭터 행동과 관계: 원소 성질은 인물과 관계의 모티프를 제공하되 인간관계를 결정하지 않는다.
- 공부: 주제를 선택해 지식을 공개·강화하고 시험, 대화, 미션에 대비한다.
- 함께 공부: 캐릭터 말투를 유지하며 개념을 가르치거나 복습하고, 필요시 호감도에 영향을 준다. O가 가장 강한 축이지만 다른 공략 캐릭터도 참여할 수 있다.
- 미션: 단서와 주기율표를 이용해 맞는 인물·물건·답을 식별하거나 공부 관련 부탁을 해결한다.
- 주기율표: 1~20번 원소의 이름·기호·원자번호·족·주기·전자배치를 확인하고 실제 결정을 내리는 도구로 사용한다.
- 시험: 10일, 20일, 30일에 게임에서 학습·강화한 승인 개념의 이해를 평가한다.
- 루트·이벤트 조건: 학습한 화학이 사건 이해와 조건 충족에 도움을 주되, 필수 조건은 이해 가능하고 도달 가능하며 결정적으로 설계한다.

권장 미션 흐름은 다음과 같다.

`캐릭터 요청 → 단서 확인 → 공부 또는 주기율표 조회 → 학교에서 선택·행동 → 미션 해결 → 관계·서사 결과`

모든 미션을 화학 문제로 만들 필요는 없다. 다만 전체 게임에서 화학 지식이 없을 때와 있을 때의 판단·해결 가능성이 실질적으로 달라야 한다.

## 9. 캐릭터 모티프 적용 기준

| 인물 | 허용되는 과학 연결 | 반드시 지킬 경계 |
|---|---|---|
| H | 원자번호 1, 1주기, 1족 위치, 전자 하나를 접근성과 입문 역할의 영감으로 사용 | H를 알칼리 금속과 동일시하지 않음 |
| C | 2주기 14족, 원자가전자 4개를 관계망·연결 중심 루트의 영감으로 사용 | 결합 개념을 인간관계의 필연 법칙으로 만들지 않음 |
| O | 2주기 16족을 족·주기·전자배치 비교와 공부 체계의 중심으로 사용 | 정답 전달용 설명 캐릭터로 축소하지 않음 |
| F | 2주기 17족, 원자가전자 7개를 Cl과 비교 | 반응성 등을 폭력성으로 단순 등치하지 않음 |
| Na | 3주기 1족, 원자가전자 1개를 H·Na·K 비교에 사용 | H와 완전히 같은 성질·성격으로 처리하지 않음 |
| Cl | 3주기 17족, 원자가전자 7개를 F와 비교 | F와 같은 성격으로 복제하지 않음 |
| Ne | 2주기 18족, 채워진 최외각 전자껍질을 일반 상호작용의 낮은 효율과 연결 | 안정성을 무감정·관계 불능으로 등치하지 않음 |

## 10. 콘텐츠 작성 절차

2026-10-26 실험 후보 조사는 `docs/17_CHEMISTRY_EXPERIMENT_RESEARCH.md`를 참고한다. ACS·RSC 원문은 과학·교육 접근의 근거이며 모든 원문 활동을 한국 고1·원소 1~20의 필수 콘텐츠로 승인한 것이 아니다. 모형 탐구와 반응을 구분하고, 실제 플레이어의 관찰·이해를 수치형 아바타 보상으로 대체하지 않는다(결정 058). 최종 활동·설명 범위는 별도 검토한다.

1. 사용할 개념이 핵심 교육 범위와 원소 1~20 안인지 확인한다.
2. 원자번호·기호·이름·족·주기·전자배치는 정본 원소 데이터에서 가져온다.
3. 문장에 과학 사실과 서사적 해석이 섞였다면 각각 구분해 검토한다.
4. 플레이어가 해당 지식을 어디에서 배우거나 조회할 수 있는지 연결한다.
5. 미션·선택·시험이 암기만 요구하지 않고 비교나 판단으로 이어지는지 확인한다.
6. 루트 필수 지식이면 조건을 무작위화하지 않고 발견·도달 가능하게 만든다.
7. 과학 담당 검토 후 QA가 정본 일치, 범위, 표현, 경계값을 검사한다.

## 11. 과학 QA 체크리스트

### 데이터 정확성

- [ ] 1~20번 원소가 각각 한 번씩 존재한다.
- [ ] 원자번호가 1부터 20까지 빠짐없이 정확하다.
- [ ] 기호의 철자와 대소문자가 정확하다.
- [ ] 한국어·영어 이름이 정본 표기와 일치한다.
- [ ] 모든 족·주기 값이 정확하고 서로 일관된다.
- [ ] 전자껍질별 전자 수가 원자번호와 일치한다.
- [ ] 전자배치 표기가 안쪽 껍질부터 동일 형식으로 작성됐다.
- [ ] 원자가전자 정보가 승인된 교육 수준과 해당 원소에 맞는다.
- [ ] H를 알칼리 금속과 단순 동일시하지 않는다.

### 단일 소스

- [ ] 주기율표, 공부, 미션, 대화 논리, 시험, 캐릭터 프로필이 하나의 원소 정본을 참조한다.
- [ ] 장면·문항·프로필에 원자번호·족·주기·전자배치가 독립 정본처럼 중복 정의되지 않았다.
- [ ] 구조화해야 할 과학 사실이 임의 이벤트 플래그에 흩어져 있지 않다.
- [ ] 정본 수정 시 모든 소비 영역에 대한 회귀 검사가 존재한다.

### 교육 범위와 용어

- [ ] 필수 학습과 평가가 고등학교 1학년 수준을 넘지 않는다.
- [ ] 시험과 필수 미션이 원자번호 20 밖 지식을 요구하지 않는다.
- [ ] 오비탈 혼성화, 분자 오비탈, 고급 양자역학·열역학·전기화학, 대학 결합 이론, 상세 반응 속도론, 전문 상수 암기를 요구하지 않는다.
- [ ] 족, 주기, 전자배치, 전자껍질, 원자가전자, 안정한 전자배치 용어를 문서 전체에서 일관되게 쓴다.
- [ ] 전자배치의 교육용 단순화가 모든 화면과 문항에서 일치한다.
- [ ] 문항이 표기법 암기보다 승인 개념의 이해와 비교를 평가한다.

### 서사와 게임플레이

- [ ] 서사 문장이 정본 과학 사실과 모순되지 않는다.
- [ ] 과학적 성질과 인물 성격·연애 관계를 일대일 법칙으로 제시하지 않는다.
- [ ] 같은 족의 유사성을 동일한 성질이나 동일한 성격으로 과장하지 않는다.
- [ ] 모든 대화가 퀴즈나 교과서 설명으로 변하지 않는다.
- [ ] 공부와 주기율표 정보가 대화, 미션, 시험, 루트·이벤트 판단 중 하나 이상에 실제로 쓰인다.
- [ ] 필수 과학 정보는 플레이 전에 배우거나 플레이 중 조회할 수 있다.
- [ ] 핵심 교육 이벤트는 무작위 실패가 아니라 이해 가능하고 결정적인 조건을 사용한다.
- [ ] O의 함께 공부 장면은 설명만 하지 않고 상호작용과 캐릭터성을 보존한다.
- [ ] Ne의 18족 모티프가 “감정 없음”으로 표현되지 않는다.

### 시험과 회귀

- [ ] 10일, 20일, 30일 시험 모두 승인된 과학 범위만 출제한다.
- [ ] 각 문항의 정답과 해설이 정본 원소 데이터와 일치한다.
- [ ] 게임에서 배우거나 강화하지 않은 범위가 갑자기 필수 시험에 나오지 않는다.
- [ ] 저장·불러오기 후 학습 상태와 주기율표 공개 상태가 설계대로 복원된다.
- [ ] 저장·불러오기로 필수 시험 또는 필수 과학 학습 조건을 우회할 수 없다.
- [ ] 과학 데이터 변경 후 미션 정답, 대화 조건, 시험 채점, 캐릭터 프로필에 불일치가 없다.
