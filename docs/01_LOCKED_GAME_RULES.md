# 잠금 게임 규칙

## 1. 문서 목적과 변경 통제

이 문서는 `docs/00_PM_MASTER_SPEC.md`의 변경 불가 제품 규칙을 실무용으로 압축한 기준서다. 원칙적으로 마스터 스펙이 우선하지만, 사용자가 잠금 규칙의 변경·예외를 명시적으로 승인하고 `docs/10_DECISION_LOG.md`에 기록한 경우에는 해당 후속 결정이 마스터 사본의 기존 문구를 대체한다. 마스터 사본과 이 문서의 차이는 결정 기록의 명시적 supersession을 따라야 하며, 이를 문서 불일치로 보고 임의로 되돌리지 않는다.

- `LOCKED` 규칙은 사용자 승인 없이 변경할 수 없다.
- 구현 편의, 일정, UI 제약은 잠금 규칙을 바꿀 근거가 아니다.
- 잠금 규칙에 영향을 주는 타협안은 담당자 문제 기록, PM의 영향·대안 정리, QA 위험 검토, 사용자 승인 순으로 처리한다.
- 미해결 사항은 임의로 확정하지 않는다. 승인된 구현 세부 사항과 제안은 잠금 규칙과 구분해 기록한다.
- 과학 사실과 서사적 해석은 분리한다. 서사는 과학적 성질을 인물과 사건에 활용할 수 있지만 사실을 바꿀 수 없다.
- 현재 사용자 승인 잠금 변경·예외는 남성 주인공 고정(결정 015), 즉시 Character End와 미래 시험 미실행(결정 020), 시험 중 제한된 기본 주기율표 조회(결정 021)다. 이 예외는 상세 콘텐츠나 코드의 자동 승인을 뜻하지 않는다.

## 2. 제품 정체성과 실행 환경

- 제목은 **《러브 앤 케미스트리 (Love & Chemistry)》**다.
- 장르는 연애 시뮬레이션, 비주얼 노벨, 학교생활 시뮬레이션, 과학 교육 게임이다.
- 정적 프런트엔드 웹 애플리케이션이며 GitHub Pages 배포가 목표다.
- 백엔드, 서버 데이터베이스, 로그인·인증, 서버·클라우드 저장, 실행에 필요한 서버 의존성, 클라이언트의 필수 비공개 API 키를 사용하지 않는다.
- 저장은 원칙적으로 브라우저 `localStorage`를 사용하며 외부 계정 없이 플레이할 수 있어야 한다.
- 저장소 하위 경로 배포와 정적 직접 배포를 지원하고, 절대 경로 때문에 자산이 깨지지 않아야 한다.
- 음향은 사용하지 않는다. BGM, 효과음, 음성 연기, 음량 설정 및 음향 하위 시스템을 만들지 않는다.
- 본작은 연애 시뮬레이션 외피를 씌운 퀴즈 사이트가 아니다. 플레이어가 배운 화학을 학교 세계에서 행동과 판단에 사용해야 한다.

## 3. 세계와 플레이어

- 배경인 **화학고등학교**는 기능적으로 평범한 고등학교다.
- 학생들은 원소를 의인화한 존재이며, 성격·습관·관계·미션·루트 장치에 원소 성질을 반영할 수 있다.
- 승인 없이 비밀 연구소, 마법 체계, 정부 음모, 초자연적 화학 능력, 과도한 설정을 추가하지 않는다.
- 플레이어는 전학 온 고등학교 2학년의 평범한 인간이며, 학교생활 연애 시뮬레이션 설정상 혼자 산다.
- 플레이어 이름은 사용자가 입력하고 변경할 수 있다.
- 사용자 결정에 따라 플레이어는 **남성 주인공으로 고정**한다. 성별 선택 기능은 없으며 상태의 `gender`는 고정값 `male`이다. 이름은 계속 사용자가 입력하고 변경할 수 있다.
- 남성 확정은 주인공 외형 확정이 아니다. 머리·눈·체형·키·복장 등 캐릭터 비주얼은 계속 유예하며 임의로 발명하지 않는다.

## 4. 과학 교육 경계

- 필수 학습 범위의 상한은 대한민국 고등학교 1학년 수준의 화학이다.
- 주 교육 데이터는 원자번호 1~20 원소로 한정한다.
- 핵심 학습 내용은 원자번호, 원소명, 원소 기호, 족, 주기, 해당 수준의 전자배치·전자껍질 분포와 적절한 원자가전자 추론, 같은 족과 유사한 화학적 성질의 관계, 주기와 점유 전자껍질의 관계, 안정한 전자배치, 1~20번 원소의 기초 비교다.
- 오비탈 혼성화, 분자 오비탈 이론, 고급 양자역학·열역학·전기화학, 대학 수준 결합 이론, 상세 반응 속도론, 전문 수치 상수 암기 등 고급 화학을 필수 학습으로 요구하지 않는다.
- 20번 밖 원소는 명시적으로 승인된 비평가성 분위기 요소가 아닌 한 다루지 않는다.
- 과학 사실은 하나의 정형화된 원소 데이터 원천에서 관리한다. 주기율표, 미션, 대화 논리, 시험, 캐릭터 프로필이 같은 원천을 참조하며, 서사 데이터가 사실을 재정의하지 않는다.
- 화학적 상호작용은 연애 관계와 일대일로 동일시하지 않는다. 화학은 기계적·주제적 은유이지 인간관계 법칙이 아니다.
- 세부 기준은 `docs/02_SCIENCE_BIBLE.md`를 따른다.

## 5. 30일 학기와 하루 구조

- 한 회차는 **30일짜리 한 학기**다. 현재 날짜를 `DAY 07 / 30`과 같이 명확히 표시한다.
- 성공한 회차는 결정 020의 Character End 조건을 충족하면 Day 30 전에 terminal로 끝날 수 있다. 이는 30일 학기와 Day 10·20·30 시험 규칙에 대한 사용자 승인 예외이며, 종료 뒤 아직 도달하지 않은 미래 Day와 시험은 실행하지 않는다.
- 일반 등교일의 거시 순서는 아침 조회 → 오전 수업 → 점심 자유 시간 → 오후 수업 → 방과 후 자유 활동 → 귀가·하루 종료다.
- 점심과 방과 후가 주요 플레이어 선택 구간이다. 인물 만나기, 미션, 공부, 해금된 데이트·관계 이벤트, 동아리·활동 이벤트, 장소 상호작용, 필요시 아이템 사용을 배치할 수 있다.
- 하루에 모든 행동을 할 수 없어야 하며, 정확한 행동 비용은 별도 승인 대상이지만 30일의 자원 압박은 의미 있게 유지한다.

## 6. 학교 공간과 매점

- 기본 공간은 교실, 교문, 특별교실·과학실, 운동장, 복도, 계단, 옥상이다.
- 추가 공간은 제안할 수 있으나 불필요하게 늘리지 않는다.
- 매점은 이동 가능한 지도 장소가 아니라 버튼·인터페이스로 접근한다.
- 매점은 아이템 구매, 미션 물건 획득, 선물 관련 플레이를 지원할 수 있다.

## 7. 수업, 공부, 주기율표

- 수업은 과학·화학 중심이며, 플레이어가 잠금 교육 범위 안에서 공부할 주제를 선택한다.
- 공부는 지식·주기율표 정보 해금 또는 공개, 시험 준비, 대화 이해, 캐릭터 미션 해결, 함께 공부 이벤트에 실질적으로 연결한다.
- 공략 캐릭터와 함께 공부하는 기능은 핵심 기능이다. 장면은 캐릭터 말투를 지키고 화학을 가르치거나 강화하며, 선택적으로 호감도에 영향을 줄 수 있지만 설명문만 이어지는 장면이 되어서는 안 된다.
- O가 함께 공부 기능의 가장 강한 루트 축이지만 O 전용 기능은 아니다.
- 플레이 중 원소 1~20의 기호·이름·원자번호·족·주기·교육 수준에 맞는 전자배치를 확인할 수 있는 주기율표를 제공한다.
- 주기율표는 장식용 도감이 아니라 요청 해결과 의사결정에 사용하는 게임플레이 도구다.
- 일곱 학습 주제는 각각 숙련도 `0~3`을 사용한다. 무료 일과 수업은 선택 주제가 `0`일 때만 `1`로 올리며, 이미 `1` 이상이면 숙련도를 올리지 않는 복습·진단이다.
- 숙련도 `2`와 `3`은 점심·방과 후의 혼자 공부 또는 함께 공부처럼 자유 행동 슬롯을 소비하는 학습으로만 얻는다. 무료 수업이나 미션 보상으로 대체하지 않는다.
- 숙련도 `1`은 시험 범위 체크리스트·기초 오답 진단과 족·주기 필터, `2`는 대화 해석 단서·미션 비정답형 힌트·두 원소 비교, `3`은 복합 비교 도구·승인 범위 안의 심화 오답 설명·일부 더 나은 해결 또는 대화 선택의 이해·해금을 제공한다.
- 숙련도는 시험 점수를 자동 보정하거나 정답을 선택하지 않는다. 원소 1~20의 핵심 사실은 숙련도와 무관하게 주기율표에서 기본 조회할 수 있다.
- 루트 도달성 예산의 시험 공부 행동은 유지하며 무료 일과 수업으로 대체할 수 없다.

## 8. 시험과 퇴학

- 활성 회차가 Day 10, 20, 30에 도달하면 해당 시험을 반드시 시행한다. Character End로 먼저 terminal이 된 회차에는 이후 미래 시험을 시행하지 않는다.
- 시험은 승인된 고등학교 1학년 수준 범위만 다루고, 게임에서 강화한 개념의 이해를 평가한다.
- 점수는 100점 만점이다.
- 어떤 필수 시험이든 **50점 미만이면 즉시 퇴학 및 게임 오버**다. 기준을 완화하지 않는다.
- 경계값은 `49점 = 퇴학`, `50점 = 생존`, `100점 = 생존`이다.
- 저장·불러오기로 필수 시험을 건너뛸 수 없어야 한다.
- 현재 시험 phase에 있거나 해당 Day의 필수 시험 시점에 도달했는데 시험을 완료하지 않았다면 Character End 자격 판정을 보류한다. 시험을 우회할 수 없으며, 제출 점수가 50점 미만이면 엔딩 후보보다 퇴학이 우선한다. 이미 통과한 시험은 다시 실행하지 않고, Character End로 종료한 뒤의 미래 시험은 실행하지 않는다.
- 시험 중에는 행동 비용 없이 주기율표를 조회할 수 있다. 원소 1~20의 정본 원자번호, 기호, 한국어·영어 이름, 족, 주기, 전자껍질별 전자배치, 승인된 원자가전자 정보와 기본 공간 배열·원소 상세만 허용한다.
- 시험 문맥에서는 검색, 숙련도 기반 족·주기 필터, 두 원소 비교, 복합 비교, 미션·대화 힌트, 오답 진단을 비활성화한다. 조회는 답을 자동 선택하거나 점수를 보정하지 않는다.
- 시험 답안, 문항 순서, 현재 문항 위치를 유지한 오버레이·도구 화면으로 열며 닫으면 동일 문항으로 복귀한다.

## 9. 호감도와 루트 성공

- 일곱 공략 캐릭터는 서로 독립된 호감도를 가지며 모두 **10**에서 시작한다.
- 전역 상태 기준은 `0 미만 = 어색함·관계 악화`, `10 = 기본 지인`, `20 이상 = 친한 친구`, `40 이상 = 연애 긴장·썸`, `80 이상 = 연애 성공 가능 기준`이다.
- 호감도는 증가, 감소, 유지될 수 있고 캐릭터마다 증감 양상이 다를 수 있다.
- 호감도 80만으로는 성공할 수 없다. **호감도 80 이상 + 필수 루트 미션·이벤트 완료 + 루트 결말 조건 도달**이 모두 필요하다.
- 반복 행동으로 호감도만 올리고 필수 미션을 무시해 루트를 완료할 수 없어야 한다.
- 행동·이벤트의 비용, 보상, 호감도, 미션·이벤트 플래그를 반영하는 효과 트랜잭션을 완전히 성공시킨 직후 엔딩 자격을 계산한다. 부분 효과 상태에서는 계산하지 않는다.
- 시험 보류 조건이 없다면 자격 후보가 1명일 때 실패 없는 최종 캐릭터 장면을 재생한 뒤 정확히 그 Character End와 메타 해금을 terminal 상태로 원자 커밋한다. 자격 획득 뒤 결과를 뒤집는 숨은 실패나 추가 선택은 없다.
- 하나의 다인 이벤트 효과로 2명 이상이 동시에 새 자격을 얻으면 그 효과로 자격을 얻은 후보만 즉시 표시한다. 플레이어가 한 명을 선택하고 선택하지 않은 후보는 확정하지 않으며, 실패 없는 선택 캐릭터 장면 뒤 정확히 하나의 Character End만 terminal로 원자 커밋한다.

## 10. 미션, 인벤토리, 상호작용

- 미션은 캐릭터별 학교생활 부탁으로 구성한다. 가져오기, 찾기, 인물 찾기, 전달, 학교 업무 돕기, 주기율표 지식으로 대상·물건·답 식별, 공부 요청 등을 사용할 수 있다.
- 모든 미션이 화학 문제일 필요는 없지만, 게임 전체에서는 화학 지식이 미션 완료에 실질적으로 기여해야 한다.
- 권장 흐름은 `캐릭터 요청 → 단서 확인·공부·주기율표 조회 → 학교에서 행동 → 해결 → 관계·서사 결과`다.
- 플레이어는 선물, 미션 물건, 학교생활 물건, 필요시 공부 관련 물건을 담는 인벤토리를 가진다.
- 인벤토리를 복잡한 역할수행게임 장비 체계로 만들지 않는다.
- V1에 별도 아케이드 미니게임은 필요하지 않다. 날짜·시간 관리, 자유 시간 선택, 장소 이동, 미션, 인벤토리, 공부, 주기율표, 시험, 호감도, 이벤트 조건, 루트 계획으로 상호작용성을 확보한다.
- 단지 게임플레이가 있다는 명목으로 무작위 화학 미니게임을 넣지 않는다. 전용 미니게임은 목적·분위기·교육 범위에 맞고 새 기능 승인을 받은 경우에만 추후 추가할 수 있다.

## 11. 결말

- 캐릭터 엔드는 호감도 80 이상, 필수 미션·이벤트 충족, 루트 결말 조건 도달 시 성립한다. 연인 관계가 되고 캐릭터별 결말이 재생되며 관련 CG를 해금할 수 있다.
- Character End 자격은 자격을 완성한 효과 트랜잭션 직후 즉시 판정한다. 단, 현재 시험 또는 이미 도달한 필수 시험이 미완료면 합격 완료까지 보류하고, 50점 미만 퇴학을 우선한다. 자격 확정 뒤에는 미래 Day·시험을 진행하지 않는다.
- 공략 성공 없이 진행한 회차는 Day 30 종합 시험을 반드시 치른다. 합격 후 방과 후와 `dayEnd`까지 완료한 뒤 **노멀 엔드**로 terminal 커밋하며 Day 31은 없다. 오류나 진행 불가 상태가 아닌 유효한 결말이어야 한다.
- 필수 시험에서 50점 미만이면 **퇴학 게임 오버**다.
- 캐릭터 엔드, 노멀 엔드, 퇴학 게임 오버는 모두 도달 가능해야 한다.
- 시험은 고정 10문항·문항당 10점이며 `49/50/100` 경계 테스트를 유지한다. 시험 중에는 위에서 제한한 기본 주기율표 조회만 허용한다.

## 12. 저장과 복구

- 주 저장 단위는 **날짜 기반 스냅샷**이다. 장면별 자유 저장을 주 규칙으로 사용하지 않는다.
- 저장에는 최소한 현재 날짜, 플레이어 정보, 캐릭터별 호감도, 루트·이벤트 플래그, 미션, 인벤토리, 점진형인 경우 학습·주기율표 지식, 시험 점수, 해당 결말·해금 상태가 포함된다.
- 날짜 스냅샷 경계, 저장·불러오기, 스키마 버전, 손상 데이터 대체 처리, 개발 중 스키마 변경 이관을 설계한다.
- 불러오기는 날짜와 필수 상태를 결정적으로 복원하고 필수 시험이나 루트 선행 조건을 훼손하지 않아야 한다.
- 누락·손상·구버전 저장 데이터에는 정의된 안전한 대체 처리가 있어야 하며 `undefined`, `NaN`, 선택 이벤트 누락에 따른 소프트락이 발생하지 않아야 한다.
- CG 해금은 제안에 따라 별도 메타 진행으로 저장할 수 있다.
- Character End 종료 저장은 선택한 결말 하나, 종료 Day, 이미 완료한 시험 결과, 관련 메타 해금을 함께 원자 커밋한다. 종료 뒤 미래 시험의 미응시 상태는 오류가 아니며 실행 대상으로 복원하지 않는다.

## 13. 홈과 CG 갤러리

- CG 갤러리는 **홈·타이틀 화면에서만** 접근할 수 있다.
- 진행 중 게임 메뉴에서는 접근할 수 없다.
- 잠금·해금 상태와 루트·이벤트 연결을 지원하고, 승인된 잠금 표현을 넘어 스포일러를 노출하지 않는다.

## 14. 캐릭터와 관계 불변 기준

공략 캐릭터는 H, C, O, F, Na, Cl, Ne의 일곱 명이며, Ne는 숨겨진 고난도 루트다. 아래 비시각적 정체성은 잠겨 있다.

| 인물 | 학년·역할 | 성격·말투·진행 불변 기준 | 과학·미션 축 |
|---|---|---|---|
| H | 1학년, 초반 진입 후배 | 친근하고 호기심 많고 밝으며 고립을 싫어하지만 속마음은 쉽게 보이지 않는다. 빠르고 표현적인 말투로 주인공을 자주 “선배”라 부른다. 초반 상승은 쉽지만 깊은 진전에는 개인 이벤트가 필요하며 진지한 감정 무시·아이 취급은 실패 요인이다. | 원자번호 1, 1주기, 1족 위치와 전자 하나의 단순성을 진입 역할에 활용하되 알칼리 금속과 동일시하지 않는다. 탐색·가져오기·동행·분실물 미션. |
| C | 2학년, 사회관계 중심 | 누구와도 자연스럽게 어울리고 관찰·중재에 능하지만 자신의 욕구를 직접 드러내기 어렵다. 친밀해질수록 장난기가 늘며, 후반은 직접 상호작용만으로 완주할 수 없다. | 2주기 14족, 원자가전자 4개를 연결망 중심 루트의 영감으로 사용한다. 인물 연결·중재·다인 미션과 타인 관련 이벤트가 중요하다. |
| O | 2학년, 같은 반 모범생 | 책임감 있고 정확하며 설명을 잘하는 약한 완벽주의자다. 남을 돕는 데 익숙하지만 도움받기는 서툴다. 차분하고 정확한 말투를 유지하며, 답만 빼가고 노력하지 않으면 실패한다. | 2주기 16족이며 공부 체계와 족·주기·전자배치 비교의 중심이다. 시험 준비·자료 탐색·함께 공부 미션. |
| F | 1학년, 고위험 후배 | 판단과 감정이 빠르고 솔직하며 성급하다. 짧고 직설적으로 말하고 고전적 츤데레처럼 감정을 숨기지 않는다. 호감도 증감 폭이 크며 우유부단·모호한 약속·번복은 실패 요인이다. | 2주기 17족, 원자가전자 7개이며 Cl과 비교한다. 목표가 명확하고 일관성을 요구하는 미션. |
| Na | 2학년 타 반, 학교생활 사건 중심 | 활동적이고 사교적이며 행동이 생각보다 앞서는 사랑스러운 사고뭉치다. 친근한 동갑 말투로 사람과 사건을 끌어들인다. 잠긴 `반복적 참여 거부`는 일반적인 타 루트 선택이 아니라 관계 맥락에서 지속적으로 Na를 배제하거나 책임을 회피하는 서사 선택을 뜻한다. | 3주기 1족, 원자가전자 1개이며 H·Na·K 같은 족 학습에서 H의 차이도 보인다. 다인·매점·학교 행사·충동의 수습 미션. |
| Cl | 3학년, 신뢰를 천천히 쌓는 선배 | 엄격해 보이지만 책임감 있게 후배를 챙긴다. 건조하고 절제된 말투 안에서 관심이 드러난다. 초반 상승은 느리고 신뢰 후 안정적이며 무책임·편법·약속 파기는 실패 요인이다. | 3주기 17족, 원자가전자 7개이며 F와 의도적으로 비교한다. 정리·전달·후배 지원·약속 준수 미션. |
| Ne | 3학년, 숨겨진 고난도 루트 | 적대적이지 않지만 혼자서도 편안하고 타인의 평가를 크게 필요로 하지 않는다. 짧고 담백하게 말한다. 보통의 좋은 선택은 대체로 0 또는 1만 오르고 선물은 대개 비효율적이며, 신호를 무시한 대화·선물 반복으로 공략할 수 없다. | 2주기 18족의 안정한 최외각 전자껍질을 평범한 상호작용이 다르게 작동하는 체험에 활용한다. 관찰·단서·특수 조건 중심이며 조건은 어렵되 발견·도달 가능해야 한다. |

세부 비시각 정보도 다음과 같이 유지한다.

- **H:** 전학생을 먼저 알아보고 다가온다. 적응력·친화력·분위기 전환이 강점이고, 고립을 불편해하며 진지한 자기 성찰을 피할 수 있다. 새로운 사람·장소, 함께하는 활동, 작고 재미있는 물건·간식을 좋아하고 무시당함, 기다림, 어린아이 취급을 싫어한다. 쉬는 시간에 학교를 돌아다니며 주인공을 보면 자연스럽게 따라다닌다.
- **C:** 누구와도 어색함 없이 말하며 전학생을 자연스럽게 맞는다. 중재·관찰·넓은 인간관계가 강점이고, 모두에게 맞추다 자신의 욕구를 놓칠 수 있다. 사람 관찰, 색다른 조합, 여러 활동 시도, 나누기 좋거나 흥미로운 물건을 좋아하고 불필요한 편 가르기와 취향을 억지로 분류하는 일을 싫어한다. 복도에서 늘 누군가와 대화하며 사소한 정보를 기억한다.
- **O:** 빈틈없이 침착하고 도움을 주는 첫인상이다. 신뢰성·집중력·설명력이 강점이고, 완벽주의와 타인에게 기대기 어려운 점이 약점이다. 정리된 필기, 계획대로 진행되는 일, 함께 공부, 유용한 문구류를 좋아하고 부주의한 “이 정도면 됐어” 태도와 무질서하거나 쓸모없는 물건을 싫어한다. 쉬는 시간에 필기를 재정리하고 명백한 개념 오류를 지나치기 어렵다.
- **F:** 호불호를 즉시 드러내고 반응을 숨기지 않는다. 결단력·정직함·추진력이 강점이고, 조급함과 지나치게 직설적인 표현이 약점이다. 빠른 결과, 명확한 답, 활기찬 활동, 바로 쓸 수 있는 물건을 좋아하고 모호함, 미루기, 회피, 약속 위반을 싫어한다. 흥미가 생기면 바로 계획하고 빠른 결론을 원한다.
- **Na:** 거의 즉시 친한 척하며 주인공을 학교생활로 끌어들인다. 주도성·친화력·사건을 만드는 힘이 강점이고, 생각보다 먼저 행동해 일을 키울 수 있다. 친구, 매점 간식, 학교 행사, 함께하는 활동을 좋아하고 혼자 아무것도 하지 않는 시간과 지나치게 격식적인 고립을 싫어한다. 점심에 사람을 모으고 주인공도 자연스럽게 계획에 넣는다.
- **Na 호감도 해석:** 다른 캐릭터를 공략하기 위한 일반 초대 거절, 일정 충돌, 미리 알린 정중한 불참은 기본 `0`이다. 명시적 약속 파기, 책임 전가, 이미 수락한 공동 계획에서의 무책임한 이탈처럼 관계적으로 부정적인 행동에만 승인된 `-3/-6` 등을 적용할 수 있다. 이 해석은 Character Bible의 잠긴 실패 성향을 바꾸지 않는다.
- **Cl:** 전학생에게 특별한 관심 없이 필요한 말만 하는 첫인상이다. 책임감·판단력·세심함이 강점이고, 높은 기준과 느린 감정 개방이 약점이다. 정돈된 공간, 믿을 수 있는 사람, 실용적인 물건, 조용한 시간을 좋아하고 무책임, 약속 위반, 남에게 수습을 미루는 어질러진 상태를 싫어한다. 눈앞의 학교 문제를 완전히 외면하지 못하고 해결하는 편이다.
- **Ne:** 말을 걸면 답하지만 관계를 만들 필요가 없어 보이는 첫인상이다. 독립성·침착함·분명한 개인 기준이 강점이고, 기본적으로 관계 유지에 노력을 거의 들이지 않는 점이 약점이다. 혼자 있는 시간, 옥상, 조용한 풍경, 개인 시간을 좋아하고 불필요한 간섭, 강요된 친밀감, 과도한 관심을 싫어한다. 방과 후나 사람이 적은 곳에서 혼자 지내며 먼저 접촉하는 일이 드물다.

잠긴 관계 씨앗은 다음과 같다.

- H·Na: 족 위치 유사성이 행동의 미묘한 평행을 만들지만 나이와 성격은 다르다.
- F·Cl: 같은 족의 단호한 핵심이 성숙도와 기질 차이로 다르게 나타난다.
- Ne·F·Cl: 18족과 인접 17족의 대비를 보여준다.
- C·전체: C는 사회관계 연결 중심이다.
- O·C: 믿을 만한 동급생으로 O는 계획하고 C는 사람을 연결한다.
- O·Na: O는 Na의 충동성에 피로를 느끼지만 싫어하지는 않는다.
- Na·Cl: Na가 일을 만들고 Cl이 수습하는 반복적 대화 관계다.
- H·F: 같은 학년이지만 사람에게 접근하는 방식이 강하게 대비된다.
- Cl·Ne: 서로 과도하게 간섭하지 않아 편안한 같은 학년 선배들이다.
- C·Ne: C도 Ne의 거리를 쉽게 좁히지 못해 Ne의 독자성을 드러낸다.

1~20번 원소는 모두 학교 세계의 인물로 존재한다. 나머지 13명은 즉시 과학 데이터와 최소 식별자만 만들고, 기능 제안 전 완성된 성격을 과도하게 확정하지 않는다. 주요 루트 의존성을 만드는 조연 확장은 PM 승인 대상이다.

## 15. 서사 가드레일

- 인물은 각자의 불변 기준, 말투, 장단점, 선호·비선호, 호감도 양상과 실패 성향을 유지한다.
- 평범한 고등학교의 현실적인 학교생활 분위기를 유지한다.
- 화학은 상황, 공부, 선택에서 나타나며 루트 진전에는 관계와 미션·이벤트가 모두 필요하다.
- 조연은 강의식 설명이 아니라 족·주기 비교와 학교생활 사건을 지원한다.
- 모든 대화를 화학 문제나 교과서 말투로 만들지 않는다.
- “반응성이 큰 원소는 폭력적”, “안정한 원소는 감정이 없다”처럼 과학 특성을 성격과 단순 등치하지 않는다.
- 필수 교육 이벤트와 핵심 루트 조건을 진행을 깨뜨리는 무작위성에 맡기지 않고 이해 가능하고 결정적인 조건을 우선한다.

## 16. 시각 자산 잠금과 유예

- 일반 비주얼 노벨 장면은 반신 캐릭터 스프라이트와 표정 변화를 사용한다.
- 특별 이벤트는 CG·이벤트 일러스트를 사용한다.
- 캐릭터의 머리, 눈, 체형, 정확한 키, 의상 변형, 장신구, 화풍, 표정 시트, CG 시각 모티프와 이미지 생성 프롬프트는 현재 **결정 유예**다. 임의로 확정하거나 캐릭터 그림을 생성하지 않는다.
- 캐릭터 스프라이트·인물 포함 CG는 향후 캐릭터 특화 생성 도구, 배경·인물 없는 자산은 비용 효율적 도구를 사용할 계획이며 UI는 가급적 HTML/CSS로 구현한다.
- 현재는 자리표시자와 안정된 자산 경로·목록 규약을 사용한다.

## 17. 필수 기능 상태와 데이터 계약

- 필수 제품 상태는 홈·타이틀, 새 게임·플레이어 설정, 불러오기, 홈 전용 CG 갤러리, 날짜 전환·요약, 대화 장면, 점심 선택, 방과 후 선택, 장소·이벤트, 공부, 주기율표, 인벤토리, 매점, 미션 상태, 시험, 결과·퇴학, 결말이다. UX상 화면을 합칠 수 있으나 기능 동작은 보존한다.
- 논리 데이터 영역은 원소, 캐릭터, 관계, 날짜·달력, 장면, 선택지, 미션, 아이템, 매점 상품, 공부 주제, 시험·문항, 호감도 규칙, 이벤트 플래그, 결말, 갤러리 해금, 자산 목록으로 분리한다.
- UI 내부에 루트 논리를 직접 흩어 놓지 않고 데이터 중심 구조를 우선한다.
- 캐릭터 성격도 하나의 정본에서 관리하고 장면은 식별자로 참조한다.
- 내부 플래그는 안정된 식별자와 문서화된 의존성을 사용하고 순환 선행 조건을 피한다. 구조화된 원소 사실을 임의 플래그로 분산하지 않는다.

## 18. 릴리스 차단 기준

다음 상태에서는 통합·릴리스할 수 없다.

- 잠금 요구 위반 또는 정본 과학 데이터와의 모순
- 도달 불가능한 캐릭터 엔드·노멀 엔드·퇴학 게임 오버
- 호감도 80만으로 필수 루트 조건을 우회하거나 Ne 루트를 단순 반복으로 돌파하는 상태
- 저장 손상, 비결정적 복원, 필수 시험 우회, 필수 조건 누락에 따른 진행 불가
- 진행 중 메뉴에서 CG 갤러리에 접근 가능하거나 홈에서 접근 불가능한 상태
- 음향 UI나 유령 음량 설정이 남은 상태
- GitHub Pages 빌드·배포 실패 또는 자산 경로 오류
- Character End 자격을 효과 트랜잭션 완료 전 계산하거나, 도달한 필수 시험을 우회하거나, 퇴학보다 엔딩을 우선하거나, 복수 후보에서 둘 이상의 엔딩을 확정하는 상태
- 시험 중 허용 범위를 넘어 검색·필터·비교·힌트·오답 진단을 제공하거나 답안·문항 순서·현재 위치를 잃는 상태
