# 사용자 플레이 구상 대조 및 체크리스트

**점검일:** 2026-10-26

**대상 기준:** `50ddb52`의 기존 Markdown 41개, 전체 12,419줄. 모든 파일의 전체 텍스트를 검사하고 이번 구상과 관련된 제품·과학·캐릭터·서사·시스템·UX 원문 절을 대조했다. 검토 파일별 용도는 7절에 기록한다.

**판정:** 큰 방향은 기존 제품과 일치한다. 조건부 충돌·새 규칙·미정 세부를 아래 체크리스트로 분리한다. 이번 작업은 대조·질문 등록이며 잠금 규칙 변경, 상세 콘텐츠 확정, QA 합격 또는 코드 구현 승인이 아니다.

## 1. 이번 사용자 구상 기록

- 첫날은 학교를 돌아다니며 인물과 대화하는 튜토리얼에 가깝다.
- 두근두근 문예부를 참고한 배경·인물·대사·선택지 중심의 전형적인 연애 시뮬레이션 UX다. 행동과 인물의 성격은 대화를 통해 경험한다.
- 플레이어 상태와 호감도에 따라 특별 데이트 등 후속 사건이 달라진다.
- “5일차 이상 교류가 없을 시” 아쉬움을 표현하거나 호감도를 올리기 어려워진다.
- 같은 행동에 대한 다른 반응의 원인으로 다른 인물과의 호감도 관계도 고려 중이다. 물음표가 붙은 검토 아이디어이지 자동 질투 규칙의 확정 지시로 해석하지 않는다.
- 일과를 마친 뒤 날짜 전환 화면으로 다음 Day로 넘어간다. 참고는 얀데레 시뮬레이터의 일과 종료·날짜 전환 방식이다.
- 점심에 공부하면 공략에 도움이 되는 정보를 얻고 대화 선택지가 넓어진다.
- 매점 간식을 선물할 수 있고 캐릭터별 호불호가 다르며, 간식 자체를 좋아하지 않는 인물도 있다.
- 주기율표는 원소·공략 캐릭터의 특성을 도감처럼 확인하는 도구다.
- 과학실에서 전자껍질 개수·화학 반응 관련 실험을 하며 특정 인물의 호감을 얻을 수 있다.
- 과학실 실험 데이트는 호감도 **15 이상**, 선택 인원은 **최대 2명**이라는 구상이다. 수치는 그대로 기록하며 적용 대상·인원 계산·효과는 확정하지 않는다.

## 5. 현재 권고하는 해석 / 아직 확정 아님

1. Day 1은 고정 일과의 소개 연출과 슬롯을 쓰는 실제 교류를 구분하면 기존 하루 구조를 깨지 않고 튜토리얼로 만들 수 있다.
2. 미교류는 모두의 호감도를 자동 차감하기보다 인물에 맞는 대사·다음 교류 반응으로 표현하는 쪽이 현재 캐릭터성과 잘 맞는다. 상승 난도를 실제 바꾸려면 회복성과 루트 도달성을 함께 검증한다.
3. 다른 인물과의 관계는 실제 사건·약속의 맥락으로 사용하고 자동 질투 공식으로 통일하지 않는 편이 C·Na·Ne의 기존 설정을 보존한다.
4. 주기율표 안에서 **과학 사실**과 **발견한 인물 정보**를 구분하면 도감 구상과 단일 과학 정본을 함께 지킬 수 있다. Ne의 과학 정보는 상시 조회하되 히든 공략 정보는 별도로 다룬다.
5. 호감도 15의 실험 활동은 친한 친구·연애 단계와 별개의 초기 교류 이벤트로 해석할 수 있다. 그것이 연인 관계의 성립이나 필수 루트 완료를 뜻하지 않게 한다.
6. 실험은 학교생활 속 VN 선택과 관찰로 시작할 수 있다. 별도 미니게임·자유 조합 반응 시뮬레이터까지 필요한지는 이후 범위 결정으로 남긴다.
